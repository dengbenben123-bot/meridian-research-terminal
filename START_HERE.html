Publish Meridian 5.0 with Coolify

This package contains the Vue 3 / FastAPI terminal, Dockerfiles, four-service Compose stack, locked dependencies, checks and complete source.

This edition runs on a Docker host managed by Coolify. The existing Cloudflare Worker remains a separate 4.4.1 deployment. Do not paste this project's source into the Cloudflare code editor.

  1. Extract the ZIP. Put the contents of meridian-coolify/ at the root of your Git repository. You should see frontend/, backend/ and docker-compose.yml at that root.
  2. In Coolify, create an Application from that Git repository. Choose Docker Compose, base directory / and Compose file /docker-compose.yml.
  3. Set runtime variables. Two are required:
    NameValue
    POSTGRES_PASSWORDA strong private database password. Preserve it for future deployments.
    MERIDIAN_AUTH_DIGESTCopy the existing terminal digest from your Cloudflare settings, or generate a new one using the configuration helper below.

    Defaults are AkShare primary, optional Tushare, a ten-second polling interval and paper trading. Leave TUSHARE_TOKEN blank unless you have an eligible account. The full variable list is in README.md.

  4. Assign your HTTPS domain to the frontend service, internal port 80. Set the health-check path to /healthz. Keep database, Redis and backend ports internal.
  5. Select Deploy. Wait for all dependencies to become healthy. Initial image builds can take several minutes.
  6. Open https://YOUR-DOMAIN/healthz. Expect:
    {"status":"ok","version":"5.0.0"}
    Then open the terminal and enter its existing username/password. These credentials are separate from your Cloudflare, Google or Coolify login.

Generate configuration without running a local website

If you need new terminal credentials, run this in the extracted folder:

py scripts/setup.py

On Linux/macOS use python3 instead of py. The helper writes a private .env with the digest and a random PostgreSQL password. Copy its values into Coolify; never commit that file. This command starts no website.

If you choose “Docker Compose Empty”

Use docker-compose.coolify-empty.yml. First upload the project contents to the root of a public Git repository. Set SOURCE_REPOSITORY_URL (ending in .git) and SOURCE_GIT_REF (branch or commit), plus the two required variables. This Compose file fetches its build contexts from Git; pasting a local-context Compose file alone cannot upload source from your computer.

Use and verify

Press . for the keyboard wizard; search gzmt or a ticker, press Enter for F5, then F9 for details. Esc returns. Check the source timestamp, EDB chart, saved workspace and watchlist. Paper orders require a preview and a separate submission.

For optional read-only checks against your deployed domain:

py scripts/verify_live.py https://YOUR-DOMAIN

What has and has not been verified

Production compilation and 45 automated checks passed. Actual source requests returned selected stocks, an ETF, an index, daily bars, financial data, company information, macro/news, futures, bonds and FX quotes. The broad stock scan was partial; the options fallback supplied contract reference data without current prices. These distinctions are shown in the interface.

No local website was started. Docker image startup, the complete PostgreSQL/Redis/proxy stack and a hosted URL have not been tested on a supplied Coolify server. Full Wind parity, universal real-time coverage and live broker execution are not implemented. See README.md and checks/ for details.

If a panel fails, keep the exact error and source status. For a deployment failure, inspect the failing service's logs. Repeated UI redeployment does not repair an upstream data outage.
